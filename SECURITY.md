# Security

## Report a vulnerability

Email [hello@nooks.place](mailto:hello@nooks.place) with "security" in the
subject. Include what you found, the file or URL, and the steps to reproduce it.

Do not include credentials, OAuth tokens, API keys or personal data in a report.
If you already sent a secret, say so without repeating it. We will ask for a safe
way to share details if needed.

## In scope

- The files in this repository: the plugin manifests, the skill, the docs, the
  validator and the workflow.
- The public Nooks endpoints this plugin uses, including
  `https://nooks.place/api/mcp-v2` and the profiles under it.
- The public Nooks site and workbench pages linked from this repository.

## Out of scope

- Other people's builds, accounts or data.
- Load tests, denial-of-service attempts or automated scanning that disrupts the
  service.
- Findings that need a credential you were not given.

## What to expect

There is no bug bounty and no promise of payment. We will acknowledge reports as
soon as we can and tell you what we find. Please do not disclose a vulnerability
publicly before we have had a chance to respond.
